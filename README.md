# AutoCrop

AutoCrop is a lightweight desktop tool that automatically crops image files based on smart content detection. Whether you're trimming screenshots, cleaning up exported graphics, or prepping visuals for documentation, AutoCrop gets it done with zero fuss.

Built with Python and Tkinter, packaged as a standalone EXE — no install, no dependencies, just click and crop.

---

## ✨ Features

- 🖼️ Auto-crops images with edge detection
- 🧠 Simple drag-and-drop interface
- 📦 Portable EXE — no setup required
- ⚡ Fast and intuitive for everyday use

---

## 💡 Why I Built It

I created AutoCrop to help myself crop out image assets for use in **Pygame** projects. I couldn’t find a simple tool that did exactly what I needed — so I built one. Now it’s fast, clean, and tailored for game dev workflows and beyond.

---

## 🚀 Getting Started

1. Download `AutoCrop.zip` from the [Releases](https://github.com/jjar7266/AutoCrop/releases) page  
2. Unzip the folder  
3. Double-click `AutoCrop.exe` to launch

No installation or Python setup required.
